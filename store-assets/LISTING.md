# VolumeSilencer Store Listing

## Name

VolumeSilencer - Tab Volume Control

## Short description

Control page media volume and quiet noisy tabs from a compact on-page widget.

## Full description

VolumeSilencer puts a simple black-and-white volume controller directly on the page you are viewing.

Set HTML video and audio volume from 0–100, mute the current tab, quiet every other tab in the window, or silence the entire window without hunting for the source of an unexpected sound. When you restore a window, VolumeSilencer returns tabs to the mute state they had before.

Features:

- Compact draggable widget that stays over the current page
- Direct page-media volume control
- Current-tab mute and unmute
- Quiet all other tabs in the current window
- Mute and restore the entire current window
- Dynamic detection of media added after page load
- Optional per-website volume memory
- Keyboard shortcut and toolbar toggle
- No account, analytics, ads, or remote data transmission

VolumeSilencer works on normal HTTP and HTTPS webpages. Browsers do not allow extensions to run on protected internal pages or store pages.

Produced by Wiplash.ai and released under the MIT License.

## Permission explanations

### Storage

Stores user-selected settings, website volume preferences, widget visibility and position, and temporary mute restoration state locally in the browser.

### Tabs

Identifies the active tab and changes browser-level mute state for current-window controls. Tab details are not transmitted.

### Website access

Finds HTML video/audio elements and renders the user-controlled widget on normal webpages. Page content and media metadata are not collected or transmitted.
