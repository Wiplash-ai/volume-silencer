# VolumeSilencer Privacy Policy

Effective August 2, 2026

VolumeSilencer is designed to work without sending user data to Wiplash.ai or another remote service.

## Data the extension reads

VolumeSilencer reads the active tab's hostname, title, audible state, and mute state to identify the page being controlled and display local status. It finds HTML `video` and `audio` elements on normal webpages to adjust their volume. It reads the tabs in the current browser window only when the user requests a window-level mute action.

## Data stored locally

VolumeSilencer may store:

- default volume and interface preferences;
- volume levels remembered by website hostname;
- website hostnames where the user left the widget visible;
- widget position; and
- temporary mute-state information needed to restore tabs after a window-level mute action.

This information remains in browser extension storage on the user's device.

## Data transmitted

VolumeSilencer does not transmit browsing history, URLs, tab titles, website content, media metadata, settings, identifiers, analytics, crash reports, or usage events. The extension contains no advertising SDK, analytics SDK, account system, or remote API integration.

## User control

Users can disable website volume memory, clear saved website controls, reset settings, or uninstall the extension. Browser extension-data behavior determines when local extension storage is removed after uninstalling.

## Future services

If a future release adds optional synchronization or another remote service, this policy and the extension's store disclosures will be updated before that functionality is released. The current version does not provide such a service.
